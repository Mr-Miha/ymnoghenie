# 🦖 Рекс и таблица умножения

Интерактивный тренажёр таблицы умножения для детей. Внутри — динозаврик Рекс, группы яиц, сложение, игры и коллекция из 67 динозавров.

**Репозиторий:** https://github.com/Mr-Miha/ymnoghenie

**Живая версия:** включите GitHub Pages в Settings → Pages → Deploy from a branch → `main` / `root`. После этого приложение откроется по адресу https://mr-miha.github.io/ymnoghenie/

## Что внутри

- **Карта чисел 1–10** — у каждого числа свой прогресс: яйцо → трещинка → малыш → взрослый.
- **Изучаем и понимаем** — пошаговые примеры с группами яиц и цепочкой сложения, лайфхаки для 2, 5, 9 и 10.
- **Покорми динозавра** — четыре варианта ответа и умная подсказка без готового результата.
- **Спаси яйцо** — экранная клавиатура и серия из пяти верных ответов.
- **Таблица Пифагора 10×10** — подсветка прямоугольника и разложение на сложение.
- **Лаборатория умножения** — ползунки, группы, точечные матрицы и переместительный закон.
- **Коллекция из 67 динозавров** — короткий факт о каждом, новый друг открывается за пять верных ответов.
- **Звуки** на Web Audio API с кнопкой включения и выключения.
- **Прогресс** сохраняется в `localStorage` браузера.
- **Установка как приложение** — манифест, иконка и офлайн-режим через service worker.

## Запуск

Просто откройте `index.html` в браузере. Для проверки офлайн-режима и установки запустите локальный сервер:

```bash
python -m http.server 8765 --bind 127.0.0.1
```

Затем откройте http://127.0.0.1:8765/
